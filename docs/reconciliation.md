# 对账方法：ziwei-chart vs 文墨天机

> 本文档说明精度验证的方法论与边界。**对账数据本身为私有资产，不在本仓库。**

## 一、对账范围（已验证）

- 样本：120 盘（覆盖不同年干×地支×性别×时辰）
- 字段：十二宫干支、主星、辅星、小星（adjStars）、十二长生、博士/将前/岁前十二神、自化（星/向心离心/符号）、12 限大限四化（宫名/宫干/岁段/四化）、命宫、身宫、五行局、生年四化

## 二、验证方法

1. 同一生辰分别由本引擎与文墨天机排盘
2. 逐字段归一化比对（繁简/全角半角/别名/分隔符）
3. 差异三分类：引擎错 / 输入错 / 口径差异
4. 引擎错 → 修复 → 全量回归（全部样本重跑）

## 三、已知口径边界（文档化，非错误）

| 项 | 本引擎口径 | 说明 |
|:--|:--|:--|
| 流月命宫 | 斗君法（流年支逆数生月顺数生时） | 蔡明宏《飞星紫微》+iztro 同源 |
| 辛年天魁钺 | 魁寅钺午（WMT 校正） | iztro 默认魁午钺寅为错 |
| 岁前十二神 | 岁破位（文墨金标准口径） | iztro 默认配置为大耗 |
| 大限岁段 | 虚岁起运（五行局数） | 火六局 6 岁起 |
| 子时 | 0时=早子时当日；23-0:59归当天 | 文墨金标准 |

## 四、参与对账（众包）

发现差异可在 <https://zwge.cn/ziwei> 提交对照结果，复核确认的引擎错误将被修复，贡献者获积分奖励。
